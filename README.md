# Yoga Studio Management Dashboard

A responsive web dashboard designed for yoga studios to manage students, class schedules, attendance tracking, and membership analytics.

---

## Overview

This dashboard provides studio owners and instructors with a centralized interface to monitor student activity, track class attendance, view financial statistics, and manage memberships with full Persian (RTL) language support.

---

## Features

- **Student Management:** View, register, and update student profiles and membership statuses.
- **Attendance & Class Scheduling:** Track daily attendance, monitor class capacity, and organize instructor schedules.
- **Interactive Visual Analytics:** Integrated dynamic charts powered by Chart.js for tracking student retention, monthly growth, and attendance metrics.
- **RTL & Persian Typography:** Custom-tailored typography utilizing Vazirmatn and Lalezar fonts with seamless right-to-left layout alignment.
- **Responsive Interface:** Adaptive layout optimized for desktop, tablet, and mobile browsers.

---

## Technologies Used

- **Markup & Structure:** HTML5 (Semantic & RTL layout)
- **Styling:** CSS3 (Flexbox, Grid, Custom Properties)
- **Logic & Interactions:** Vanilla JavaScript (ES6+)
- **Data Visualization:** Chart.js 4.4
- **Typography:** Google Fonts (Vazirmatn, Lalezar)
- **Deployment:** Netlify

---

## Quick Start

1. Clone the repository:
   ```bash
   git clone https://github.com/Devix-dev/yoga-dashboard.git
   cd yoga-dashboard
   ```

2. Open the dashboard:
   Open `index.html` directly in any modern web browser or serve via Live Server.
